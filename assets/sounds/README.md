# ZEN-1's recorded sounds

Public-domain (CC0) recordings only, each checked on its own Freesound page (9 Oct 2026). `tools/zen_samples.py`
cuts, filters, loops and codes them into `firmware/src/dsp/zen_samples.h`, all at one loudness. The files here
are Freesound's high-quality previews.
